# Hosting and DNS rules (read before every task)

This repo serves the registration form at form.spurcorpacademy.com on GitHub Pages only.

The landing page is a different repo (NearFarAdvisory/spurcorpacademy-home) and is served at spurcorpacademy.com.

Rules:
- Never use Netlify or the domains.co.za hosting for these sites.
- Never add, edit or delete a DNS record.
- Never change the GitHub Pages custom domain or the CNAME file.
- If you think a hosting or DNS change is needed, stop and tell the owner what and why. The owner makes the change.
